# SOP: Processing an Agent Refund Request
**Version:** 1.0 (draft) | **Owner:** Not specified (see Open Questions) | **Last updated:** 25 Nov 2026

## 1. Purpose
Refund travel agents correctly and consistently for cancelled bookings, and keep them updated on progress.

## 2. Scope
Applies to refund requests from travel agents, mainly for flight cancellations. Whether hotels and packages are included is Not specified.

## 3. Roles and Responsibilities
| Role | Responsibility |
|---|---|
| Travel agent | Sends the refund request by email or message to their relationship manager (RM) |
| Relationship manager (RM) | Checks booking status and airline refund eligibility, calculates the refund, forwards to the refunds team |
| Refunds team | Processes the refund in the system and credits the agent's wallet |

## 4. Step-by-Step Procedure
1. **Receive the request.** The RM receives the agent's refund request by email or message.
2. **Check booking status.** The RM confirms the current status of the booking.
3. **Check airline rules.** The RM checks whether the airline allows a refund for this booking.
4. **Calculate the refund.** The RM works out the amount using the airline's rules and the company's own fee. (Fee amount: Not specified.)
5. **Send to the refunds team.** The RM forwards the request, with the calculation, to the refunds team.
6. **Process the refund.** The refunds team processes it in the system. The refund goes back to the agent's wallet.
7. **Share a ticket number.** Give the agent a ticket number so they can ask for status without chasing the RM.
8. **Confirm to the agent.** Tell the agent once the refund is credited.

## 5. Exceptions and Escalations
- **International bookings:** refunds may take longer than the usual "few days". (Exact timelines: Not specified.)
- **Airline has not yet refunded the company:** it is unclear whether the agent is paid before the airline refunds. Possibly done in some cases for big agents. Not confirmed.
- **Agent keeps asking for status:** point them to the ticket number from Step 7.
- **Escalation contact for delayed refunds:** Not specified.

## 6. Checklist
- [ ] Request received from the agent
- [ ] Booking status checked
- [ ] Airline refund rules checked
- [ ] Refund amount calculated (airline rules and company fee)
- [ ] Request sent to the refunds team
- [ ] Refund processed and wallet credited
- [ ] Agent given a ticket number and told when the refund was credited

## 7. Metrics
- Time from request to wallet credit, split into domestic and international
- Number of agent status enquiries per refund
